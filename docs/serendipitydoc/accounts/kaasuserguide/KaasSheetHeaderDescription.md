# Kaas Sheet - Transactions (Past) Sheet Header Descriptions

This document outlines the header definitions for the **Transactions (Past)** sheet, detailing the purpose and requirements of each column in the table.

---

## **1. Basic Transaction Details**

- **TrNo**:  
  This refers to a Unique Identification Number which starts from Number 1 and goes on.

- **Date**:  
  This particularly shows the date when a transaction is made from various payment modes like Bank, Credit Card, or Cash.

- **Description**:  
  This is the primary description that showcases the immediate nature of the specific transaction.

---

## **2. Financial Details**

- **Amount**:  
  The monetary value involved in the transaction, which will always be in Rupees symbol either with a negative sign or positive sign.

- **Payment Mode**:  
  This denotes the mode in which the transaction is made for actual payments. It also includes the credit transactions processed. The modes include:  
  *(ICICI Current, ICICI, Credit, ICICI-CC-9003, ICICI-CC-1009, SBI-CC-7670, and Cash)*.

---

## **3. Account and Department Information**

- **AccID (Account ID)**:  
  Account ID refers to the unique ID numbers allotted for every transaction made through various accounts.

- **Department**:  
  The department to which this transaction is linked or accounted for. Departments include:  
  *(Trademan, Serendipity, and Dhoom Studios)*.

---

## **4. Additional Details**

- **Comments**:  
  This column is for additional notes to enter the complete details of the transactions made.

- **Category**:  
  This denotes the category type of the transaction, which should be within:  
  *(Salaries, Income, Maintenance, Chits, EMI, and Hand Loans)*.

- **ZohoMatch**:  
  This column indicates whether the transaction has hit the Zoho platform or not:
  - **Yes** – for the transactions present in the Zoho APP
  - **No** – for transactions not available (e.g., transacted through Cash, Credit Card, or other banks not linked to Zoho)

---

This structured documentation aids in understanding the purpose and data requirements for each column in the Transactions (Past) sheet.
